## Análisis de Vulnerabilidades en routes/products.js

Tras revisar el código, he identificado varias vulnerabilidades de seguridad importantes:

### 🔴 **1. Exposición de Datos Sensibles**
**Línea 48**: `router.get('/analytics/stats', ProductController.getProductStats);`  
**Línea 49**: `router.get('/export', ProductController.exportProducts);`  
**Problema**: Estas rutas exponen estadísticas y exportación de productos sin autenticación.

**Corrección**:
```js
// Mover estas rutas a la sección de administrador
router.get('/admin/analytics/stats', adminAuth, ProductController.getProductStats);
router.get('/admin/export', adminAuth, ProductController.exportProducts);
```

### 🔴 **2. Falta de Validaciones de Entrada**

**Línea 44**: `router.get('/search', ProductController.searchProducts);`  
**Problema**: No hay validación de parámetros de búsqueda, puede causar inyección NoSQL/SQL.

**Corrección**:
```js
const searchValidation = [
  query('q')
    .trim()
    .isLength({ min: 1, max: 100 })
    .matches(/^[a-zA-Z0-9\sáéíóúñÁÉÍÓÚÑ\-]+$/)
    .withMessage('Término de búsqueda no válido'),
  query('category')
    .optional()
    .isIn(['hombre', 'mujer', 'deportivos', 'hoodies-sacos', 'chaquetas'])
    .withMessage('Categoría no válida'),
  query('minPrice')
    .optional()
    .isFloat({ min: 0 })
    .withMessage('Precio mínimo no válido'),
  query('maxPrice')
    .optional()
    .isFloat({ min: 0 })
    .withMessage('Precio máximo no válido')
];

router.get('/search', searchValidation, ProductController.searchProducts);
```

**Línea 45**: `router.get('/category/:category', ProductController.getProductsByCategory);`  
**Problema**: No valida el parámetro de categoría.

**Corrección**:
```js
const categoryValidation = [
  param('category')
    .isIn(['hombre', 'mujer', 'deportivos', 'hoodies-sacos', 'chaquetas'])
    .withMessage('Categoría no válida')
];

router.get('/category/:category', categoryValidation, ProductController.getProductsByCategory);
```

**Línea 57**: `router.post('/batch', adminAuth, ProductController.batchOperations);`  
**Problema**: Operaciones en lote sin validación pueden ser muy peligrosas.

**Corrección**:
```js
const batchValidation = [
  body('operation')
    .isIn(['update', 'delete', 'updateStock'])
    .withMessage('Operación no válida'),
  body('productIds')
    .isArray({ min: 1, max: 100 })
    .withMessage('Debe especificar entre 1 y 100 productos'),
  body('productIds.*')
    .isMongoId()
    .withMessage('ID de producto no válido'),
  body('data')
    .optional()
    .isObject()
    .withMessage('Los datos deben ser un objeto válido')
];

router.post('/batch', adminAuth, batchValidation, ProductController.batchOperations);
```

### 🔴 **3. Validaciones Insuficientes**

**Líneas 32-35**: Validación de imágenes insuficiente  
**Problema**: Solo valida que sea un array, no el contenido.

**Corrección**:
```js
body('images')
  .isArray({ min: 1, max: 10 })
  .withMessage('Debe incluir entre 1 y 10 imágenes'),
body('images.*')
  .isURL({ protocols: ['http', 'https'] })
  .matches(/\.(jpg|jpeg|png|webp)(\?.*)?$/i)
  .withMessage('Las imágenes deben ser URLs válidas con formato jpg, jpeg, png o webp')
```

**Líneas 28-31**: Validación de tallas insuficiente  
**Corrección**:
```js
body('sizes')
  .isArray({ min: 1, max: 7 })
  .withMessage('Debe incluir entre 1 y 7 tallas'),
body('sizes.*.size')
  .isIn(['XS', 'S', 'M', 'L', 'XL', 'XXL', 'XXXL'])
  .withMessage('Talla no válida'),
body('sizes.*.stock')
  .isInt({ min: 0, max: 9999 })
  .withMessage('Stock debe ser un número entre 0 y 9999')
```

### 🔴 **4. Falta de Rate Limiting**
**Problema**: No hay limitación de velocidad en rutas críticas.

**Corrección**:
```js
const rateLimit = require('express-rate-limit');

// Rate limiting para búsquedas
const searchLimiter = rateLimit({
  windowMs: 1 * 60 * 1000, // 1 minuto
  max: 30, // máximo 30 búsquedas por minuto
  message: 'Demasiadas búsquedas, intente más tarde'
});

// Rate limiting para operaciones de admin
const adminLimiter = rateLimit({
  windowMs: 1 * 60 * 1000, // 1 minuto
  max: 10, // máximo 10 operaciones por minuto
  message: 'Demasiadas operaciones administrativas, intente más tarde'
});

router.get('/search', searchLimiter, searchValidation, ProductController.searchProducts);
router.post('/batch', adminAuth, adminLimiter, batchValidation, ProductController.batchOperations);
```
